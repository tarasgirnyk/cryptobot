# CryptoBOT — документація продукту

Оновлено: 8 жовтня 2026 року.

**Почати тут: [зведена концепція та план запуску](PROJECT_OVERVIEW.md).**
В одному документі зібрано продукт, клієнтський шлях, останні тарифи,
партнерську програму, аудиторію, маркетинг, систему, відкриті питання й план дій.

Закрита SaaS-платформа автоматизованої торгівлі через Binance API.
Доступ за рефералом, кошти на біржі клієнта, API без права виведення.
Погоджена робоча модель: п'ять рівнів 50/35/25/15/10%; підключення
100 USD у USDT, із яких 50 USD — кредит на майбутні комісії; мінімум
100 USD/місяць із третього рівня за додатного розрахункового прибутку
як нижня межа плати, не доплата. Збитковий/нульовий місяць та інші
відкриті умови окремо перелічені в документах.
